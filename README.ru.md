# Bot Importer для SillyTavern

[English](README.md) | Русский

Импортируйте много карточек персонажей за один раз. Для каждого бота можно заранее задать аватар, теги и лорбуки, не открывая самих ботов. Работает на компьютере и на телефоне.

## Установка с GitHub

1. В SillyTavern откройте панель **Extensions** (значок со стопкой блоков).
2. Нажмите **Install extension**.
3. Вставьте адрес и подтвердите:

   ```
   https://github.com/smolsn3k/st-bot-importer
   ```

4. Выберите, установить ли расширение только для вас или для всех пользователей, затем перезагрузите страницу.

Чтобы обновить расширение позже, откройте панель Extensions и нажмите кнопку обновления рядом с Bot Importer (или используйте **Manage extensions**).

### Ручная установка

Склонируйте репозиторий в папку расширений и перезагрузите SillyTavern:

```
cd SillyTavern/data/<ваш-пользователь>/extensions
git clone https://github.com/smolsn3k/st-bot-importer
```

Можно также скачать репозиторий в виде ZIP и распаковать в ту же папку. Убедитесь, что `manifest.json` лежит прямо внутри папки `st-bot-importer`, рядом с `index.js`, `lib.js`, `i18n.js` и `style.css`.

## Язык

Расширение работает на английском и русском. По умолчанию язык выбирается автоматически: если SillyTavern или браузер на русском, интерфейс будет русским. Переключить язык можно двумя способами:

- кнопка **EN / RU** в шапке окна Bot Importer;
- список **Язык** в панели Extensions, в разделе Bot Importer.

## Как открыть

- пункт **Bot Importer** в меню волшебной палочки (рядом с полем ввода чата);
- значок коробки рядом с кнопкой «Import character» в списке персонажей;
- кнопка **Открыть Bot Importer** в панели Extensions.

## Как пользоваться

1. Перетащите PNG- или JSON-карточки в окно или нажмите на область загрузки, чтобы выбрать файлы. Выбирать можно сколько угодно.
2. У каждой карточки можно:
   - нажать на картинку и выбрать новый аватар (или перетащить на неё изображение), затем обрезать его;
   - добавить или убрать теги (введите тег и нажмите Enter или запятую);
   - выбрать основной лорбук или оставить настройку самой карточки;
   - добавить любое количество дополнительных лорбуков.
3. Панель массовых действий (см. ниже) работает сразу со всеми выбранными карточками.
4. Нажмите **Импорт**. Импортированные карточки исчезают из списка, а неудачные остаются с описанием ошибки.

## Обрезка аватара

Когда вы выбираете или перетаскиваете картинку на карточку, открывается окно обрезки с рамкой 2:3.

- перетаскивайте картинку, чтобы сдвинуть её;
- масштаб меняется щипком, колесом мыши или ползунком (можно уменьшить так, чтобы картинка поместилась целиком);
- **Показать целиком** вписывает всю картинку в рамку, **Сбросить** возвращает начальную обрезку;
- **Применить** сохраняет обрезку, **Отмена** оставляет прежнюю картинку.

Маленькая кнопка обрезки на картинке карточки открывает окно снова, начиная с картинки, которую вы выбрали (или с изображения самой карточки). Если окно обрезки не нужно, снимите галочку **Открывать обрезку при выборе картинки** в панели Extensions: тогда картинки обрезаются автоматически по центру с сохранением верхней части.

## Панель массовых действий

- **Добавить теги**: введите один или несколько тегов через запятую, и они добавятся каждой выбранной карточке.
- **Удалить теги**: введите один или несколько тегов через запятую, и они будут убраны у каждой выбранной карточки. Под полем показаны все теги выбранных карточек с количеством. Нажмите на тег, чтобы убрать его у всех сразу.
- **Основной лорбук** и **дополнительный лорбук**: выберите лорбук, чтобы задать или добавить его всем выбранным карточкам.
- **Выбрать все, Снять выбор, Только уникальные, Очистить список**: быстрый выбор карточек.

## Игнорирование тегов

- Включите **Игнорировать теги из карточек** (в панели массовых действий или в панели Extensions), и все карточки будут начинаться без тегов. Теги, добавленные вами, сохраняются. Если снять галочку, теги самих карточек вернутся.
- В панели Extensions поле **Всегда игнорировать эти теги** принимает список через запятую. Эти теги убираются у всех карточек, остальные сохраняются.

Игнорируемые теги также удаляются из данных карточки, которые импортируются.

## Предупреждения о дубликатах

Карточки сравниваются со всей вашей библиотекой и друг с другом по описанию и вступительным сообщениям (первое сообщение плюс альтернативные приветствия), а не только по имени.

| Плашка | Что значит |
| --- | --- |
| Точный дубликат / Почти идентичная (красная) | Совпадают и описание, и вступление. Галочка снимается автоматически. |
| То же описание, другое вступление (оранжевая) | Скорее всего, альтернативный сценарий бота, который у вас уже есть. |
| То же вступление, другое описание (оранжевая) | То же начало, но бот переписан. |
| Похоже на другую (жёлтая) | Частичное совпадение. |
| То же имя, другое содержимое (синяя) | Совпадает только имя. Скорее всего, не дубликат. |

Нажмите **Сравнить вступительные сообщения** на плашке, чтобы увидеть оба вступления рядом. Пороги настраиваются в панели Extensions.

## Примечания

- Аватар получается размером 512×768 (2:3). Данные карточки встраиваются в новый PNG.
- Основной лорбук сохраняется как привязанный лорбук карточки. Дополнительные лорбуки сохраняются в настройках лорбуков SillyTavern для этого персонажа. Лорбуки должны уже существовать в SillyTavern.
- Теги добавляются в список тегов SillyTavern и дополнительно записываются в карточку.
- Первая проверка дубликатов на большой библиотеке занимает некоторое время, пока строится индекс. Дальше он хранится до перезагрузки страницы.
